# Bastions-Tracker-DnD-
DM-Werkzeug zum Verfolgen der Bastion Orders (D&D 2024) für das Dessarin-Anwesen. Läuft direkt im Browser (eine HTML-Datei, keine Installation).

**Funktionen:** Tage/Tendays (1 Tenday = 10 Tage), Special-Facility-Slots je Charakterstufe (5→2, 9→4, 13→5, 17→6), Craft/Harvest/Trade-Aufträge mit Fortschritt, Abklingzeiten, Siegelring-Cooldown, Charms, Kasse & Lager, Maintain-Events (W100) und Logbuch.

**Speicherung:** lokal im Browser. Zur Sicherung bzw. für andere Geräte den Stand per *Export* als JSON speichern und per *Import* laden.
