# Bastions-Tracker-DnD-
DM-Werkzeug zum Verfolgen der Bastion Orders (D&D 2024) für das Dessarin-Anwesen. Läuft direkt im Browser (eine HTML-Datei, keine Installation).

**Funktionen:** Tage/Tendays (1 Tenday = 10 Tage), Special-Facility-Slots je Charakterstufe (5→2, 9→4, 13→5, 17→6), Craft/Harvest/Trade-Aufträge mit Fortschritt, Abklingzeiten, Siegelring-Cooldown, Charms, Kasse & Lager, Maintain-Events (W100) und Logbuch.

**Speicherung:** lokal im Browser. Zur Sicherung bzw. für andere Geräte den Stand per *Export* als JSON speichern und per *Import* laden.

Hinweis: Inoffizielles Fan-Projekt unter der Fan Content Policy von Wizards of the Coast. Alle Rechte an D&D-Inhalten liegen bei Wizards of the Coast.

## Spielstand auf GitHub speichern
Mit **☁ Speichern / ☁ Laden** wird der Spielstand als `daten/bastion-stand.json` in diesem Repo abgelegt (jede Speicherung = ein Commit, ältere Stände bleiben im Verlauf). Dafür einmal pro Gerät unter *GitHub-Speicher → Einstellungen* einen Fine-grained Personal Access Token eintragen (nur dieses Repo, Berechtigung *Contents: Read and write*). Der Token bleibt ausschließlich im Browser und wird weder im Spielstand noch im Repo gespeichert.
